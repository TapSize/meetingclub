# DURY

Браузерные видеовстречи DURY. Комнаты создаются по коду; медиа передаётся между браузерами через WebRTC, PeerJS Cloud используется для сигнализации.

Инструкция по публикации через GitHub Pages и подключению Cloudflare TURN: [DEPLOY.md](DEPLOY.md).

## Запуск

Нужны Python 3 и интернет для PeerJS и Lucide из CDN. В папке проекта запустите:

```powershell
py -m http.server 8000
```

Откройте http://localhost:8000 и разрешите доступ к камере и микрофону. Для проверки вызова откройте страницу в двух браузерах или на двух устройствах.

## Возможности

- Создание и вход в комнаты по ссылке или коду.
- Главная с активными недавними комнатами; список хранится локально и очищается после закрытия host-комнаты.
- Групповые WebRTC-звонки, камера, микрофон и показ экрана.
- Индикатор качества WebRTC-соединения и подсветка участника во время речи.
- Ненавязчивые звуковые сигналы подключения, камеры, микрофона и выхода; отключаются в аудионастройках.
- Выбор микрофона и устройства вывода звука.
- Выбор камеры и разрешения 480p/720p/1080p из профиля или конференции.
- Размытие фона или собственное изображение через MediaPipe Selfie Segmentation.
- Общие панели настроек доступны как до входа, так и во время встречи.
- Изменение размеров и свободное перемещение видеоплиток, три макета и полноэкранный режим.
- Загрузка изображения профиля, профиль передаётся участникам.
- Чат, список участников со статусами микрофона/камеры и активного голоса, темы и интерфейс на русском, украинском и английском.

## Ограничения

Сигнализация зависит от публичного PeerJS Cloud, медиа идёт напрямую между участниками. Для production потребуются собственные сигнализация, STUN/TURN и управление комнатами. Переключение аудиовыхода зависит от поддержки `setSinkId` браузером.
