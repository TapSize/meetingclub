# Місце

Односторінковий прототип тимчасових відеокімнат. Зустріч створюється за коротким кодом; посилання-запрошення містить цей код та ідентифікатор організатора. Дзвінки відбуваються напряму між браузерами через WebRTC. PeerJS Cloud використовується лише для сигналізації, а не для передавання відео.

## Запуск

Потрібен Python 3 і доступ до інтернету для завантаження PeerJS та Lucide з CDN. У цій папці виконай:

```powershell
py -m http.server 8000
```

Відкрий http://localhost:8000. Для перевірки дзвінка відкрий сторінку у двох браузерах або на двох пристроях і дозволь доступ до камери та мікрофона. На телефоні відкрий адресу комп’ютера в локальній мережі, якщо браузер дозволяє доступ до медіа за цією адресою, або розгорни сайт через HTTPS.

## Можливості

- Створення зустрічі з кодом і запрошення посиланням.
- Приєднання до кімнати за кодом або посиланням.
- Груповий WebRTC-дзвінок, керування камерою та мікрофоном.
- Показ екрана; браузер може запропонувати передавання системного звуку.
- Перетягування й закріплення відеовікон, повноекранний режим.
- Віддзеркалення власного відео та налаштування кольору, яскравості й ширини підсвічування.
- Перемикання між денною та нічною темами.
- Три макети камер, фокус на співрозмовнику, повноекранний режим і постійна власна плитка.
- Список учасників з аватарами та ім’ям гостя; профіль передається іншим учасникам.
- Груповий чат із повідомленнями в реальному часі та лічильником непрочитаного.

## Обмеження прототипу

Сигналізація залежить від публічного PeerJS Cloud, а медіа передається напряму між учасниками. Для надійної роботи у продакшені знадобляться власний сервер сигналізації, STUN/TURN, керування життєвим циклом кімнат і політика приватності. Деякі мережі блокують прямі WebRTC-з’єднання. Підсвічування змінює рамку на екрані, але фізично не освітлює обличчя.
